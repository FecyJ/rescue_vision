# 二、几何模块如何封装

建议把几何部分拆成三个类，而不是做一个巨大的工具类。

## 1. `CameraModel`

负责相机自身几何：

* 加载内参和畸变参数；
* 预计算去畸变映射；
* 原始像素转去畸变像素；
* 整幅图像去畸变；
* 必要时计算像素对应的相机射线。

它不应该知道场地、机器人和 YOLO。

## 2. `GroundProjector`

负责地面平面映射：

* 去畸变像素 → 机器人地面坐标；
* 机器人地面坐标 → 去畸变像素；
* 生成鸟瞰图；
* 判断某个像素能否可靠投影到地面；
* 管理 BEV 的范围和毫米/像素比例。

它依赖 `CameraModel`，但不负责机器人全局位姿。

## 3. `TransformManager`

负责坐标系之间的刚体变换：

```text
相机坐标系
机器人坐标系
场地坐标系
```

例如：
$$
[p_f=R(\theta)p_r+t]
$$

它管理机器人当前位姿，但不处理图像。

# 三、最重要的设计原则

## 1. 明确三种像素坐标

不要全部使用 `(u, v)` 而不注明来源。至少区分：

```text
RawPixel          原始畸变图像像素
UndistortedPixel  去畸变图像像素
BevPixel          鸟瞰图像素
```

否则后期非常容易把原图关键点直接传给基于去畸变图像标定的单应矩阵。

可以用独立数据类型避免混用：

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class RawPixel:
    u: float
    v: float


@dataclass(frozen=True)
class UndistortedPixel:
    u: float
    v: float


@dataclass(frozen=True)
class GroundPoint:
    x_mm: float
    y_mm: float
```

## 2. 全部视觉算法尽量共享去畸变图像

推荐主链路：

```text
相机原始帧
    ↓
统一去畸变
    ↓
共享 UndistortedFrame
    ├── Hailo Pose
    ├── HSV危险检测
    ├── 中心十字检测
    └── 场地结构检测
```

这样：

* 模型输出关键点已经位于去畸变坐标系；
* 单应矩阵可以直接使用；
* 各模块坐标定义一致；
* 不需要每个检测器分别去畸变。

如果模型训练使用的是原始畸变图像，也可以保留原图推理，但模型输出点必须先执行“点去畸变”，再做地面投影。两种方案不要混用。

## 3. 不要每次都生成完整鸟瞰图

物资 Pose 已经给出了少量关键点，对这些点直接做单应变换即可：

```text
两个关键点
→ perspectiveTransform
→ 两个地面坐标
```

没有必要先将整幅图转换成 BEV，再去读取坐标。

完整 BEV 主要用于：

* 中心十字；
* 场地线；
* 安全区区域分割；
* 调试可视化。

因此 `GroundProjector` 应同时提供：

```python
pixel_to_ground(...)
pixels_to_ground(...)
make_bev(...)
```

点变换是高频主接口，`make_bev` 是按需接口。

# 四、核心接口示意

```python
from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

import cv2
import numpy as np


@dataclass(frozen=True)
class GroundPoint:
    x_mm: float
    y_mm: float


@dataclass(frozen=True)
class BevConfig:
    width_px: int
    height_px: int
    mm_per_pixel: float
    robot_origin_u: float
    robot_origin_v: float


class CameraModel:
    def __init__(
        self,
        camera_matrix: np.ndarray,
        distortion: np.ndarray,
        image_size: tuple[int, int],
        new_camera_matrix: np.ndarray | None = None,
    ) -> None:
        self.camera_matrix = np.asarray(camera_matrix, dtype=np.float64)
        self.distortion = np.asarray(distortion, dtype=np.float64)
        self.image_size = image_size

        self.new_camera_matrix = (
            np.asarray(new_camera_matrix, dtype=np.float64)
            if new_camera_matrix is not None
            else self.camera_matrix.copy()
        )

        self._map1, self._map2 = cv2.initUndistortRectifyMap(
            self.camera_matrix,
            self.distortion,
            R=None,
            newCameraMatrix=self.new_camera_matrix,
            size=self.image_size,
            m1type=cv2.CV_16SC2,
        )

    def undistort_image(self, image: np.ndarray) -> np.ndarray:
        return cv2.remap(
            image,
            self._map1,
            self._map2,
            interpolation=cv2.INTER_LINEAR,
        )

    def undistort_points(self, points_uv: np.ndarray) -> np.ndarray:
        points = np.asarray(points_uv, dtype=np.float32).reshape(-1, 1, 2)

        result = cv2.undistortPoints(
            points,
            self.camera_matrix,
            self.distortion,
            P=self.new_camera_matrix,
        )

        return result.reshape(-1, 2)


class GroundProjector:
    def __init__(
        self,
        image_to_ground_h: np.ndarray,
        ground_to_image_h: np.ndarray,
        bev: BevConfig,
    ) -> None:
        self.image_to_ground_h = np.asarray(
            image_to_ground_h,
            dtype=np.float64,
        )
        self.ground_to_image_h = np.asarray(
            ground_to_image_h,
            dtype=np.float64,
        )
        self.bev = bev

    def pixels_to_ground(
        self,
        undistorted_pixels: np.ndarray,
    ) -> np.ndarray:
        points = np.asarray(
            undistorted_pixels,
            dtype=np.float32,
        ).reshape(-1, 1, 2)

        ground = cv2.perspectiveTransform(
            points,
            self.image_to_ground_h,
        )

        return ground.reshape(-1, 2)

    def pixel_to_ground(
        self,
        u: float,
        v: float,
    ) -> GroundPoint:
        result = self.pixels_to_ground([[u, v]])[0]

        return GroundPoint(
            x_mm=float(result[0]),
            y_mm=float(result[1]),
        )

    def ground_to_pixels(
        self,
        ground_points: np.ndarray,
    ) -> np.ndarray:
        points = np.asarray(
            ground_points,
            dtype=np.float32,
        ).reshape(-1, 1, 2)

        pixels = cv2.perspectiveTransform(
            points,
            self.ground_to_image_h,
        )

        return pixels.reshape(-1, 2)

    def make_bev(
        self,
        undistorted_image: np.ndarray,
    ) -> np.ndarray:
        # 具体实现可使用单独的 image_to_bev_h，
        # 不一定与输出毫米坐标的矩阵完全相同。
        return cv2.warpPerspective(
            undistorted_image,
            self.image_to_ground_h,
            (self.bev.width_px, self.bev.height_px),
        )
```

实际工程中，建议明确区分：

```text
H_image_to_ground
H_ground_to_image
H_image_to_bev
H_bev_to_image
```

不要假设“地面毫米坐标矩阵”可以直接作为 `warpPerspective` 的输出图像矩阵使用。因为 `warpPerspective` 的目标仍然是像素坐标，需要额外定义地面毫米坐标到 BEV 像素的缩放和平移。

# 五、更合理的统一封装

可以再提供一个对上层更友好的门面类：

```python
@dataclass
class GeometryContext:
    camera: CameraModel
    ground: GroundProjector
    transforms: "TransformManager"

    def raw_pixel_to_robot_ground(
        self,
        u: float,
        v: float,
    ) -> GroundPoint:
        undistorted = self.camera.undistort_points([[u, v]])[0]

        return self.ground.pixel_to_ground(
            float(undistorted[0]),
            float(undistorted[1]),
        )
```

这样上层感知模块只需要调用：

```python
ground_point = geometry.raw_pixel_to_robot_ground(u, v)
```

但是底层仍保持三个模块独立，方便测试和替换。

# 六、帧对象也建议统一封装

不要在各线程之间只传裸 `numpy.ndarray`。建议使用带时间戳和坐标空间信息的帧对象：

```python
from dataclasses import dataclass


@dataclass
class VisionFrame:
    sequence: int
    timestamp_ns: int
    raw: np.ndarray
    undistorted: np.ndarray | None = None
    bev: np.ndarray | None = None
```

更进一步可以做延迟计算：

```python
class FrameGeometryCache:
    def __init__(
        self,
        frame: VisionFrame,
        camera: CameraModel,
        ground: GroundProjector,
    ) -> None:
        self.frame = frame
        self.camera = camera
        self.ground = ground

    def get_undistorted(self) -> np.ndarray:
        if self.frame.undistorted is None:
            self.frame.undistorted = self.camera.undistort_image(
                self.frame.raw
            )
        return self.frame.undistorted

    def get_bev(self) -> np.ndarray:
        if self.frame.bev is None:
            self.frame.bev = self.ground.make_bev(
                self.get_undistorted()
            )
        return self.frame.bev
```

这样：

* Pose 模型只请求去畸变帧；
* 中心十字检测请求 BEV；
* 如果本帧不需要固定结构检测，就不会生成 BEV；
* 同一帧多模块请求 BEV 时只计算一次。

# 七、配置与运行时对象分离

标定数据建议只从文件读取一次，然后构造不可变运行时对象。

```yaml
# camera.yaml
image_size: [1536, 864]

camera_matrix:
  - [fx, 0, cx]
  - [0, fy, cy]
  - [0, 0, 1]

distortion:
  - k1
  - k2
  - p1
  - p2
  - k3
```

```yaml
# ground_mapping.yaml
valid_ground_range_mm:
  forward: [150, 2500]
  lateral: [-1200, 1200]

bev:
  width_px: 480
  height_px: 500
  mm_per_pixel: 5.0

image_to_ground_h:
  - [...]
  - [...]
  - [...]
```

程序启动时：

```text
读取 YAML
→ 校验分辨率
→ 创建 CameraModel
→ 创建 GroundProjector
→ 预计算 remap
→ 检查单应矩阵是否可逆
→ 用测试点验证误差
```

运行过程中不要频繁读取配置文件。

# 八、上层检测器应如何使用

## 物资 Pose

```python
left_ground, right_ground = geometry.ground.pixels_to_ground([
    left_keypoint,
    right_keypoint,
])
```

输出：

```text
近侧边中心
目标方向
目标宽度
机器人相对坐标
```

## 中心十字

```python
bev = frame_cache.get_bev()
cross = cross_detector.detect(bev)
```

检测结果直接已经位于固定比例的地面鸟瞰坐标。

## 场地线和安全区

同样使用 BEV，但检测模块只返回几何观测：

```text
LineObservation
PointObservation
PolygonObservation
```

检测模块不应该自行修改机器人全局位姿。位姿修正统一交给定位模块。

# 九、建议尽早固定的接口边界

```text
CameraSource
    输出带时间戳的原始帧

Geometry
    像素、地面、机器人和场地坐标转换

Perception
    输出目标和固定标志观测

Localization
    使用观测修正机器人位姿

WorldModel
    根据机器人位姿维护动态目标地图

Planner
    只读取世界模型，不访问图像
```

最需要避免的是：

* YOLO 模块内部自己读取标定参数；
* 中心十字模块内部自己维护单应矩阵；
* 安全区模块直接修改全局位姿；
* 控制器直接使用检测框像素；
* 同一个 `(u,v)` 在不同模块中代表不同图像空间。

## 推荐的最终封装关系

```text
CameraModel
    负责镜头

GroundProjector
    负责地面

TransformManager
    负责坐标系

FrameGeometryCache
    负责同一帧的惰性计算与缓存

GeometryContext
    为上层提供统一入口
```

这套结构的核心是：**标定参数只有一份，坐标转换只有一个权威实现，整幅 BEV 按需生成，少量关键点直接做矩阵变换。**
