# 后续优先级

本页只保留当前开放目标和验收条件，不记录已经完成的逐项开发历史。排序原则是先做不依赖机械尺寸、最终安装位姿、底盘参数和串口协议的工作。

## 已有基线

以下软件基础已经完成并由无硬件测试覆盖：

- 两种最新帧相机源、统一 `CameraFrame` / `FrameSource`；
- pinhole、rational、fisheye 内参与地面标定兼容；
- 像素、地面和 BEV 双向转换；
- schema v2 严格运行配置、标定指纹和模型校验和校验；
- 有界异步记录、图片/视频/记录回放；
- 单会话完整回放、采集速率、丢帧和元数据健康检查；
- 记录转清单、哈希校验、按 `recording_id` 防泄漏划分；
- 分类别指标、混淆矩阵、地面误差、时延和失败索引；
- 五类 `TargetClass`、单 K0 `TargetObservation`、假后端和观测转评测记录；
- 与 HailoRT 延迟解耦的 YOLO26 Pose 后端及配置化模型资产、类别映射和阈值。

这些能力发生回归时按缺陷处理，不再作为路线图任务重复列出。最终安装后的地面误差属于 P3 现场验收。

## P0：补齐现场数据资产

依赖四类目标实物或高一致性打印件和近似场地背景，不依赖底盘。

- [ ] 按[目标数据采集清单](目标数据采集清单.md)录制绿色普通物资、黑色核心物资、橘色伤员和浅蓝危险目标。
- [ ] 同时覆盖静态、手持运动、阴影、遮挡、接触、蓝色安全区干扰和图像边缘。
- [ ] 生成带哈希的数据清单和按录像整组划分报告，记录数据版本与存储位置。

完成标准：四类目标均有可哈希验证的实拍记录；静态与运动会话可由 `RecordingSource` 回放；清单和划分命令严格通过。合成示例、棋盘图片和单个测试块不能作为关闭证据。

## P1B：跟踪、世界模型与规则状态机

依赖：已冻结的 `TargetObservation`；完全可用合成事件开发。

- 实现按时间戳关联、短时遮挡、置信衰减和过期删除。
- 建立静态区域、动态目标、对手占据和不确定性的最小世界模型。
- 集中实现首次单个普通物资、一次最多 3 个、伤员单独、危险禁送和观测过期规则。
- 用合成事件覆盖正常任务以及危险误送、伤员混运、超量、误入对方安全区等失败路径。
- 策略仅输出搜索、接近、推送、避让、交付、停止等抽象动作。

完成标准：无相机、无模型、无底盘即可重放完整任务事件；危险或过期观测产生确定且保守的降级行为。

## P1C：目标感知基线与 Hailo 适配

依赖：P0 数据和现有感知契约；不依赖底盘通信。

- 训练开发机可复现的四类基线，颜色只作为辅助证据；低置信度由运行时降级为 `unknown`。
- 使用现有 Hailo 后端完成正式单 K0 模型和目标硬件部署验证。
- 单独校准危险类别，支持疑似危险区域膨胀和保守绕行。
- 在静态集、手持运动集和目标硬件上分别评测。

完成标准：报告分类别指标与失败样例，危险类单列；树莓派 + Hailo 持续运行无延迟累积，并报告端到端 P50/P95 观测年龄。

## P1D：区域、场界与对手感知

依赖近似场地材料样本，不依赖底盘控制。

- 红/蓝安全区通过 `team_color` 映射己方/对方，区分物资区、伤员区、入口和隔板。
- 输出场界、对方安全区和安全裕量地面多边形。
- 建立不依赖对手固定图案的对手机器人/未知障碍基线。
- 颜色、线段、几何和学习模型保持可替换，围栏只作为低精度观测。

完成标准：红蓝切换只改配置；离线回放报告区域类别、边界误差和保守占据区域。

## P2：定位和规划接口

依赖场地几何；精确运动学和报文编码后置。

- 冻结场地坐标、红蓝方变换和静态地图。
- 从固定场地特征产生视觉位姿观测，并用离线数据评估误差。
- 定义里程计/IMU mock；轮距、噪声和控制周期全部从配置注入。
- 规划器只消费世界模型和可配置机器人足迹，输出抽象速度意图或路径点。

完成标准：合成轨迹可完整运行；替换底盘参数不修改感知、世界模型或规则状态机。

## P3：机械和电控冻结后

- 固定相机高度、俯仰、保护罩和焦点后的内参复核、地面外参和保留点误差验收；
- 真实轮距、轮径、编码器、IMU、速度范围和控制周期下的定位融合；
- 物理链路、报文编码、看门狗、急停和失控保护联调；
- 推送机构、机器人足迹、载荷变化和接触条件下的轨迹验证；
- 减速带、碰撞、翻倒、热降频、供电波动和 3 分钟对抗压力测试。

## 当前推荐顺序

1. 有实物时立即完成 P0 现场数据。
2. 没有实物时做 P1B 纯逻辑状态链。
3. 数据到位后做 P1C；场地材料到位后并行做 P1D。
4. 再做 P2 离线定位和规划接口。
5. 机械、电控参数冻结后集中完成 P3，避免提前写死参数。
