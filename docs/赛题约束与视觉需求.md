# 赛题约束与视觉需求

本文是官方规则到软件语义的唯一项目级映射，不记录实现状态或开发顺序。实现位置见[项目结构](项目结构.md)，开放任务见[后续优先级](后续优先级.md)。本文不替代官方文件；若资料表述不同，以最新正式命题、评分细则和现场裁判解释为准。

## 1. 场景与硬约束

| 官方要求 | 对视觉/软件的影响 |
| --- | --- |
| 约 3000×3000 mm 场地，四周有围栏 | 建立带公差的场地模型；围栏不能被假定为高精度定位基准 |
| 两队同时自主运行，每轮 3 分钟 | 需要低延迟最新帧、对手检测、碰撞风险和失控降级，不允许依赖人工干预 |
| 允许与笔记本电脑通信，但运行中不得触碰笔记本或以任何方式遥控 | 比赛只启用 `observe_only` 图传、地图和状态观察；远程运动/录制控制仅用于赛外采集或明确允许的调试，依据《命题与运行》智能救援“电控及驱动要求” |
| 机器人 ≤1.5 kg，出发尺寸 ≤300×300×200 mm | 算法必须适应固定的小型机载算力和单目相机，不依赖额外重型传感器 |
| 出发区为洋红，安全区分红/蓝且分物资区、伤员区 | 赛前抽签配置红蓝方；检测区域类别不能只用固定颜色写死“己方” |
| 出发区前有 3 根减速带，现场还有障碍和多种路面 | 视觉位置会振动、模糊和短时跳变；跟踪与时间戳不可省略 |
| 禁止抓取或把目标放在机器人上 | 视觉输出应支持推送/围拢策略所需的接触点、朝向和局部障碍，而不只是检测框中心 |

## 2. 初赛目标语义

| 类别 | 初赛外观 | 数量 | 分值/风险 | 推荐感知输出 |
| --- | --- | ---: | --- | --- |
| 普通物资 | 绿色、40 mm 正方体 | 8 | 5 分/个；首个必须单独转运 1 个 | 类别、地面接触点、中心、可推方向、置信度 |
| 核心物资 | 黑色、40 mm 正三棱锥 | 4 | 10 分/个 | 类别、底面/接触点、姿态、置信度 |
| 伤员 | 橘色、80×40×40 mm 长方体 | 4 | 15 分/个；必须一次单独转运 1 个 | 类别、长轴方向、地面接触边、置信度 |
| 危险目标 | 浅蓝、40 mm 正方体 | 4 | 进入安全区或出场会结束本轮 | 保守危险概率、膨胀避让区域、跨帧确认状态 |

现场物体存在颜色、尺寸、姿态和打印材料差异；决赛还会改变数量、形状、颜色、重量、大小、位置和任务。因此模型配置、类别映射和规则参数必须可替换，不能把初赛常量散落在代码中。

当前 ROI HSV 启动范围只依据《规则讲解》的四类目标示意图建立，并非官方
色卡。命题文件同时明确实际颜色存在偏差，因此数值只在版本化运行配置中维护，
必须用现场实物、固定相机参数和分层实拍重新校准，不能把示意图取样当作精确
颜色真值或危险类性能证据。

危险目标的错误代价高度不对称：把危险目标当成救援目标可能直接结束比赛，而暂时绕开一个疑似危险目标只损失机会。因此应分别校准危险类召回率与误报率，在策略层支持“未知/疑似危险”状态，而不是强制每个检测都四选一。

## 3. 规则状态机需求

感知结果需要服务于显式任务状态机。复合状态枚举、动作、输入输出和
安全短路顺序只在[规则状态机设计](规则状态机设计.md)中定义，本页不维护
另一套状态草图。

状态机至少维护：

- 首个普通物资是否已有效进入己方物资区；
- 当前接触/推动的目标 ID、类别和数量估计；
- 当前安全区的物资半区与伤员半区；
- 疑似危险目标与安全区/场界的距离；
- 是否进入对方安全区、是否与对手持续接触；
- 视觉数据是否过期、机器人是否超过 15 秒无有效运动。

规则状态与检测算法分离。检测器报告观测和不确定性，状态机结合历史与任务阶段做决策。
具体复合状态、输入输出、安全优先级和回放用例见[规则状态机设计](规则状态机设计.md)。

## 4. 必要感知能力

按比赛风险排序：

1. 危险目标与未知目标检测，输出可用于避让的地面区域。
2. 四类目标检测/姿态估计，并为推送提供地面接触几何。
3. 己方安全区颜色、物资/伤员分区、入口斜坡和边界检测。
4. 对方安全区与场界检测，避免扣分或出场。
5. 对手机器人、静态障碍和近场碰撞风险检测。
6. 出发区、场地结构和静态特征检测，为全局定位提供观测。
7. 目标跨帧跟踪、遮挡恢复和世界模型更新。

只检测目标框不足以完成任务。对每个可转运目标，至少需要确定适合地面投影的接触点；对长方体/棱锥还应估计朝向，以选择稳定推送方向。

## 5. 可量化验收指标

离线评测应按场景分层，而不是只报告总体 mAP：

- 各类别 precision、recall、混淆矩阵，危险类单列阈值曲线；
- 强光、阴影、颜色偏差、运动模糊、遮挡、相互接触和远近尺度分桶；
- 地面接触点误差（mm）及误差随距离的变化；
- 安全区/场界分割 IoU 或边界距离误差；
- 跟踪 ID 切换、漏跟时长和观测年龄；
- 树莓派 + Hailo 上的端到端 P50/P95 延迟、处理频率、丢帧率、温度和内存；
- 规则回放：首个目标、危险误送、伤员混运、超过 3 个、误入对方安全区等用例必须可自动判定。

指标阈值应通过后续场地实验确定；在没有数据前不伪造“合格数值”。

## 6. 资料中的差异与待确认项

- 命题 PDF 将黑色核心物资描述为“正三棱锥”，规则讲解抽取文本出现“正四面体”；训练数据应以组委会最终实物/图纸为准，并覆盖合理形态差异。
- 围栏尺寸、目标颜色和场地布置均明确允许现场偏差，不能把单次样场照片当作精确真值。
- 决赛参数现场公布，软件必须支持现场更换类别配置、模型和规则，而无需修改大量业务代码。
